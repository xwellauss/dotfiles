# dotfiles
My Dotfiles ;)

### Setting Up
```bash
ln -sr alacritty ~/.config/alacritty
ln -sr wpaperd ~/.config/wpaperd
ln -sr rofi ~/.config/rofi
ln -sr sway ~/.config/sway
ln -sr swaylock ~/.config/swaylock
ln -sr sioyek ~/.config/sioyek
ln -sr waybar ~/.config/waybar
ln -sr niri ~/.config/niri
ln -sr nvim ~/.config/nvim
ln -sr kitty ~/.config/kitty
ln -sr zsh ~/.config/zsh
ln -sr zed ~/.config/zed
ln -sr mako ~/.config/mako
```
